## 概要

本データは営業提案用であり、店舗の公式ホームページではありません。

- `script.js`：スマートフォンメニュー、表示アニメーション、西暦表示

## 画像について
店舗が安全に利用できる公式画像の直接URLと転載許可を確認できなかったため、全画像を「店舗写真に差し替え予定」の仮枠にしています。

公開前に、以下の使用許可を得た画像へ差し替えてください。
1. メインビジュアル用の料理または店内写真
2. おすすめ料理の写真
3. 店内全体、席、カウンターの写真
4. ドリンクまたは日本酒の写真
5. 外観と入口の写真
6. Instagram投稿写真
7. OGP用画像 `assets/ogp.jpg`

## デザイン変更
`style.css` 冒頭の `:root` 内にあるCSS変数を変更すると、主要な配色をまとめて調整できます。

主な変数：
- `--color-red`：アクセントカラー
- `--color-red-dark`：メニュー背景などの濃色
- `--color-navy`：メインビジュアル、アクセス背景
- `--color-paper`：全体の紙色
- `--color-gold`：補助アクセント
- `--content-width`：コンテンツ最大幅

## OGP・公開URL
`index.html` 内の以下を公開時に設定してください。
- `og:url`
- `og:image`
- 必要に応じて正式なfavicon
