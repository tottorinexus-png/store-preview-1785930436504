# 居酒家もんたや 営業提案用デモサイト

## ファイル構成
- `index.html`: ページ本文、メタ情報、各リンク
- `style.css`: 配色、レイアウト、レスポンシブ表示
- `script.js`: スマートフォン用メニュー制御
- `README.md`: 調査・公開前確認事項

## 表示方法
4ファイルを同じディレクトリに配置し、`index.html`をブラウザで開いてください。外部ライブラリやビルド作業は不要です。

## 情報掲載上の判断
営業時間は掲載媒体間で相違がありました。ホットペッパーグルメには月～土18:00～22:30・日曜定休、食べログには全日15:00～23:00と掲載されています。このため、本デモでは営業時間を断定せず、Instagramまたは電話での確認を案内しています。

料理名・価格、支払い方法、席数、個室、駐車場、喫煙条件についても、媒体間の差異または更新時期の問題があるため掲載していません。

## 公開前に必要な作業
1. 店舗へ最新の営業時間・定休日・ラストオーダーを確認する
2. 最新メニュー、価格、ドリンク情報を受領する
3. 予約方法とネット予約URLを店舗に確認する
4. 駐車場、席数、個室、禁煙・喫煙、支払い方法を確認する
5. 外観、店内、料理、ドリンク写真の提供または使用許可を得る
6. 仮画像枠を許諾済み店舗写真へ差し替える
7. 正規ドメイン決定後、canonical、OGP URL、OGP画像を設定する
8. デモ表記を残すか、正式公開時に店舗承認のうえ変更する

## 画像について
第三者サイトやInstagramの画像は、転載許可を確認できなかったため使用していません。すべてCSSによる仮画像枠です。

## 主な変更箇所
配色は`style.css`冒頭の`:root`内にあるCSS変数で変更できます。電話番号、住所、Instagram、Googleマップ、予約リンクは`index.html`内を検索して変更してください。
