# 居酒家もんたや 営業提案用デモサイト

## 概要

鳥取県鳥取市湖山町北の「居酒家もんたや」を対象に制作した、1ページ型の営業提案用デモホームページです。

スマートフォンでの閲覧を優先し、次の情報へ短い操作で到達できる構成にしています。

- 電話
- 外部ネット予約
- Googleマップ
- 営業時間
- 店舗所在地
- Instagram

## ファイル構成

- `index.html`：ページ構造、店舗情報、各リンク
- `style.css`：配色、レスポンシブレイアウト、店舗専用デザイン
- `script.js`：スマートフォンメニュー、メニュー閉鎖処理、フッター年表示
- `README.md`：調査内容、公開前確認事項、差し替え方法

## デザイン方針

掲載情報で確認できる「昭和レトロな大衆居酒屋」という特徴をもとに、次の表現を採用しています。

- えんじ色：提灯、のれん、大衆居酒屋の印象
- 濃紺：夜営業と落ち着いた店内の印象
- 生成り：紙メニューや木札を思わせる背景
- 明朝体：店名と見出しに限定して和の雰囲気を付加
- 木札風の番号、細い罫線、控えめな市松状パターン

過度な影、グラデーション、英語見出し、点滅表現は使用していません。

## 画像について

店舗が権利を持つ画像の直接利用許可を確認できなかったため、すべて仮画像枠にしています。

公開前に以下の画像へ差し替えてください。

1. メインビジュアル用の外観または料理写真
2. 店内全体が分かる写真
3. チューリップの唐揚げの最新写真
4. おすすめ料理写真
5. ドリンク写真
6. 店舗外観写真
7. OGP用横長画像

Instagramや予約サイトの写真を無断でダウンロード、転載しないでください。店舗から元データを受領するか、撮影者と店舗双方の許可範囲を確認してください。

画像を差し替える場合は、`.placeholder-photo` 要素内の仮表示を `<img>` に置き換え、内容に合う `alt` 属性を設定します。

例：

    <div class="hero-visual">
      <img src="assets/hero.jpg" alt="居酒家もんたやの料理と店内">
    </div>

必要に応じて次のCSSを追加してください。

    .hero-visual img,
    .gallery-item img,
    .shop-photo img {
      width: 100%;
      height: 100%;
      object-fit: cover;
    }

## OGP設定

`index.html` の `<head>` 内に設定位置を用意しています。

公開時は次の項目を実際の絶対URLに変更してください。

- `og:url`
- `og:image`

必要に応じて、次のcanonicalタグも追加してください。

    <link rel="canonical" href="https://公開ドメイン/">

## 動作確認

- 外部JavaScriptライブラリ不使用
- 320px以上の画面幅を想定
- スマートフォン、タブレット、PC向けレイアウトあり
- 横スクロールを抑止
- モバイルメニューはEscapeキーでも閉じられる
- `rel="noopener noreferrer"` を外部タブリンクに設定
- Googleマップは検索URLと埋め込み地図を使用

ローカル確認は、4ファイルを同じディレクトリに置いて `index.html` をブラウザで開いてください。実運用時はHTTPサーバー上での確認を推奨します。
